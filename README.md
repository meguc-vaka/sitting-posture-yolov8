====================================================================
  - 環境建置與啟動步驟
====================================================================

[步驟 1] 建立並啟用 Conda 虛擬環境
--------------------------------------------------------------------
* 建立環境: conda create -n sitting python=3.10
* 啟用環境: conda activate sitting


[步驟 2] 安裝相依套件 (Conda 環境執行必看 ⚠️)
--------------------------------------------------------------------
* 基礎安裝: pip install -r requirements.txt

* 備註說明: 若您在 Anaconda Prompt 運行 app.py 遇到相容性問題，
            請務必手動執行以下指令修正：
            
  -> 指令 A: pip install "setuptools<82"
  -> 指令 B: pip install -U ultralytics
        (建議 ultralytics == 8.4.95)


[步驟 3] 啟動應用程式
--------------------------------------------------------------------
* 啟動指令: python app.py

* 連結說明: 啟動後，請在瀏覽器中打開 http://127.0.0.1:5000 即可開始使用。
====================================================================
